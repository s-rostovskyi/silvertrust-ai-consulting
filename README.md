# SilverTrust AI Consulting

A two-day AI consulting exercise covering sector research, client discovery, and a solution proposal. I worked with Ben Mayer. As the client, I researched automotive software engineering. As the consultant, I explored online guitar learning for self-taught beginners.

## Recommendation

Pilot a practice card that helps beginners work through a difficult chord change and resume the same passage in their next session. Then test whether AI improves drill selection compared with simple rules.
